Privacy Policy

About this project

Pin Companion is a project exploring a potential integration between Pinterest and Claude using the Model Context Protocol (MCP). The integration is currently under development and is not yet available for use.

Information collection

This project website does not currently provide account registration, collect personal information through forms, or operate a Pinterest connection.

Third-party services

Any future Pinterest integration will be subject to Pinterest's API terms, permissions and privacy requirements. Any data processing practices will be explained here before the integration launches.

Data security

Security and responsible handling of information will be considered during development. No claim of operational data protection is made for an integration that has not yet been built.

Contact

For questions about this project, please use the project owner's contact details once published.
